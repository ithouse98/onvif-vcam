شبکه و دسترسی

  

    
آدرس اعلام‌شده به VMS
      
      
اگر سیستم چند کارت شبکه دارد (Hyper-V، WSL، Docker، VMware…)، IP شبکه‌ای که VMS روی آن است را انتخاب کنید. Discovery و همه آدرس‌های ONVIF/RTSP فقط همین IP را اعلام می‌کنند.

    

    
نام کاربری و رمز (همه دوربین‌ها و این پنل)

      
      
    

    
ایجنت‌ها (کامپیوترها و گوشی‌های دیگر)
      
      
با تنظیم کلید، فقط ایجنت‌هایی که با همین کلید نصب شده‌اند پذیرفته می‌شوند.

    

    

    

  

  

    






  

  

    
    
هر کپی یک دستگاه ONVIF مستقل است (UUID، نام و پورت ONVIF جدا) و برای تست بار VMS مناسب است. کپی‌ها انکودرهای دوربین اصلی را مشترک استفاده می‌کنند؛ پس ۵۰ کپی تقریباً همان CPU یک دوربین را مصرف می‌کند.
